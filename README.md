## Interactive NNgen Documentation

During my time at the University of Tokyo, I worked with Shinya Takamaeda-Yamazakis (my supervisor) [NNgen Project](https://github.com/NNgen/nngen), a fully customizable hardware synthesis compiler for deep neural networks. This repository features a simplified Python reimplementation of NNgen. The goal is not to reengineer the original project but to create a foundational resource for discussion and understanding of its underlying processes.
